# Spring Security Project

A Spring Boot application demonstrating secure authentication and authorization using Spring Security and JWT.

## Features
- User authentication with JWT tokens
- Role and permission based access control
- Custom security filters
- Secure REST API endpoints
- Modular and clean security configuration

## Tech Stack
- Java
- Spring Boot
- Spring Security
- JWT
- Maven

## How to Run
mvn spring-boot:run

This project shows backend security fundamentals for microservices and API-driven systems.
